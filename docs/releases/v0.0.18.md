## Highlights

**Android review is faster and more focused, running commands gain a live full-screen output view, active runs use one compact progress rail, and submitted screenshots remain available from the conversation.**

### Focused Android review

- Tapping an **Edited** or **Wrote** call with a recorded diff opens a full-screen file review instead of mixing the diff with tool arguments and command output.
- Large diffs now virtualize off-screen rows for smooth vertical scrolling while preserving full-width horizontal panning. The focused view contains only the file, diff, wrap control and optional **Ask about this** action.
- **Ask about this** attaches the complete file diff to the composer and returns focus to the conversation.
- The **Changed** drawer keeps its diff and per-file Review links while omitting redundant edit/write argument and output cards.

### Runs, context and conversation polish

- Tapping a running shell command opens a full-screen **Command** / **Output** view. Its virtualized output streams live, follows the tail until you scroll away, and resumes following when you return to the end.
- Main and subagent composers share the same compact working rail, ordered run segments, elapsed-time placement and Stop control.
- Background threshold compaction is labeled alongside **Working** and keeps the live run segments visible; blocking compaction remains a distinct **Compacting** state.
- Session Details keeps the run line visible while run details and Context metadata reopen folded; changed files have a direct Review row.
- Submitted prompt-image attachments can be opened again from their conversation chips.
- Empty focused composers display the insertion caret immediately, and Home no longer inserts a redundant caught-up card.

### Release operations and compatibility

- A repository skill now documents and automates the safe GitHub release sequence: explicit staging, branch CI before tagging, annotated tags, tag CI publication and final asset verification.
- Android Local continues to bundle Bun **1.4.3** and Pi/Durable SDK **1.3.0**. Install the APK in place with the existing signing key; do not uninstall it or clear app data merely to update.
- Rebuilt helpers are activated content-addressably. Existing Durable session daemons are not hot-reloaded; fresh sessions use the updated helper after activation.

Android Local and Durable remain experimental and unsandboxed. Automated validation uses faux providers and offline fixtures; it does not make live provider requests.
