## Highlights

**Android now understands trusted project-local commands, keeps long output and text interaction stable, and improves terminal compatibility.**

### Android projects and prompts

- Discover trusted project-local prompt templates and skills for the selected remote project, with caret-local slash completion that attaches commands safely before sending.
- Show Paste on the empty main-chat composer’s first long press, and keep transcript message bubbles stable while selecting text.
- Keep composer expansion and the Run so far drawer responsive while a live transcript is busy.
- Navigate multi-image prompt attachments with Previous/Next controls and an N of M indicator.

### Terminal and command output

- Scroll live wrapped and unwrapped command output reliably while preserving horizontal panning and paused tail-following.
- Add collapsible terminal controls and a licensed, generated Nerd-compatible symbol fallback while retaining Commit Mono as the primary font.

### Release safety

- Harden tag validation, artifact verification, and CI-only recovery for release publication failures.
