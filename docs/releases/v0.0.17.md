## Highlights

**Android does substantially less repeated work in long sessions, touch-and-hold follows the device accessibility setting, and completed background subagents can report into a parent run already in progress.** Stock Pi and the Durable SDK are upgraded to **1.3.0**.

### Android responsiveness and accessibility

- Long main and subagent conversations use retained virtual transcripts, while large project trees mount only visible rows. Stable keyed rows and bounded remeasurement reduce repeated layout work during streaming, scrolling and polling.
- Recently hydrated remote transcripts stay warm after idle SSH channels are released, so reopening can paint cached history while a fresh authoritative snapshot catches up. The cache is bounded and cleared safely when sessions or stores are replaced.
- Streaming shell tails and one-second updates avoid unnecessary full-transcript measurement. Large command output uses a single styled block instead of one layout node per line.
- Modal sheets reuse the retained route underneath, and the small attachment chooser no longer runs its expensive transition.
- Text selection now uses Android's configured touch-and-hold timeout, with a 400 ms fallback when the platform value is unavailable. The selection toolbar appears as soon as the hold is recognized rather than waiting for lift.
- Helper-update titles no longer repeat the computer name already present in their details.

### Durable subagents

- A completed background report now steers whichever parent run is active at the next model boundary instead of becoming a redundant follow-up. If the parent is idle, the report starts its own turn. Reports do not interrupt an active provider request or running tool.
- Android distinguishes reports steering the current run from reports waiting for the next turn.
- Sessions remain in the **Working** group while background subagents continue after the parent answer, with an explicit active-subagent count.
- Long child histories are virtualized, and deleting a session or switching stores cannot make a later child reuse stale retained screen state.
- Completed streamed reasoning folds with its tool calls; **Show** restores the chronological thoughts-and-tools stream.

### Runtime and packaging

- Stock Pi and the `pi-ai`, `pi-durable` and `pi-coding-agent` packages move from **1.2.0 to 1.3.0**.
- The standalone Durable runner and the controlled Android Local build use Bun **1.4.3**. Stock Pi's official executable retains the Bun version supplied by its upstream release.
- The normal ARM64 APK continues to bundle experimental Local mode, its source-linked Bun runtime and required notices. It requires Android 11/API 30 or newer.
- Install the APK in place with the same signing key. Do not uninstall it or clear app data merely to update.
- Remote report steering requires the v0.0.17 helper/runner. An upgraded helper does not hot-reload an existing daemon; let active work finish, then open a fresh SSH Durable session or stop an idle old owner. Android Local receives the new runner in the APK.

Android Local and Durable remain experimental and unsandboxed. Windows helpers continue to use the stock-Pi path rather than the bundled Durable runner. Automated validation uses faux providers and offline fixtures; it does not make live provider requests.
