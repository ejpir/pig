## Highlights

**Large Android activity sheets now stay responsive, and file review can collect line-anchored comments across files before sending one structured follow-up.**

### Faster activity sheets

- **Looked**, **Changed** and **Checked** sheets virtualize their content line by line, so opening and scrolling large diffs, references, commands and tool output no longer lays out the entire activity at once.
- Live command output updates incrementally, including shell progress that rewrites a line with carriage returns. Existing rows, horizontal pan positions and the visible scroll anchor remain stable as output grows.
- Copying, text selection, wrapping, full-width horizontal panning, live stage updates and compact sizing for short sheets remain available. Unwrapped full-screen command output can also be panned while it continues streaming.

### Inline review follow-ups

- Tapping diff lines opens a comment editor directly below the selected lines. Comments can include file or image attachments and remain anchored in the reviewed file.
- Multiple comments can be staged across files, reviewed or removed independently, then sent together as one structured follow-up.
- Review submissions keep follow-up semantics even if another run is active or transport admission is delayed, so feedback queues behind current work instead of unexpectedly steering it.
- Retained review rows remeasure only affected content and preserve the draft, staged comments and file context while navigating the review.

### Release operations and compatibility

- Repository tooling documents a signer-safe Android Local update path that verifies the installed certificate, bundled runtime metadata and in-place installation before replacing the APK.
- Android Local continues to bundle Bun **1.4.3** and Pi/Durable SDK **1.3.0**. Install updates in place with the existing signing key; do not uninstall the app or clear its data.
- The included inline-page and scripted-calculator materials are design and historical references, not new production runtime guarantees.

Android Local and Durable remain experimental and unsandboxed. Automated validation uses faux providers and offline fixtures; it does not make live provider requests.
