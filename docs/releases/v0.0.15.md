## Highlights

**Android Local is now available — experimental.** The release APK bundles a
source-linked Bun runtime and the unchanged Pi/Durable 1.2.0 SDK: no computer,
companion APK or separately installed Bun/Node is required for Local chats.
SSH connections and the existing shared Android interface remain available.

### Android Local (experimental)

- Choose **Local** from the Pi/computer selector and sign in with a Claude or
  Codex subscription. Native encrypted account storage owns OAuth refresh;
  inference uses request-scoped native authorization and HTTP.
- Shared sessions, model/thinking selection, streaming, images/attachments,
  Stop and stock Durable coding tools. Chats, completed history and prompt
  request identities persist in app-private SQLite across process restarts.
- Switching Local ↔ Remote or leaving a thread no longer aborts Local's tools.
  Explicit Stop, account invalidation/deletion and the existing app-background
  cancellation policy remain separate.
- Removed the obsolete QuickJS agent/custom-tool/Node-shim backend and proof UI.
  QuickJS remains only where needed for native OAuth (and existing Visualize).
- Bounded cancellation now settles unfinished HTTP bodies even when native
  release is the only terminal notification. Failed database/runtime teardown
  retains uncertain writer ownership instead of pretending the session closed.

**Important limitations:** Local is an in-process experiment, **not sandboxed or
production-security validated**. Its stock tool named `bash` runs Android
`/system/bin/sh`; this is **not GNU Bash or a bundled Linux userland**. Git,
compilers and arbitrary desktop commands are not supplied. Long background
execution, complete Activity recreation, arbitrary mid-tool crash recovery and
comprehensive live-provider interoperability are not guaranteed. Saved completed
sessions and request deduplication do not imply exactly-once external tool effects.
The experimental runtime substantially increases APK size.

### Android fixes

- Interrupted scrolling no longer leaves transcript updates and elapsed timers
  frozen after the app returns to the foreground.
- Collapsed thinking stays in the compact activity/tool group rather than
  adding full content gaps on both sides.

### Build and release

CI source-builds the pinned ARM64 Bun 1.4.3/JSC runtime, bundles it and the SDK into
the normal `dev.pi.android` release APK, and verifies their presence, architecture,
version and notices before publication. Runtime and LGPL relink-object archives
are included with release assets. The separate synthetic test package remains
`dev.pi.android.quickjstest`; it is not a replacement for the normal release APK.
Existing test installations must be upgraded without uninstalling/clearing data.

Offline validation covers native OAuth/HTTP fixtures, both provider wrappers,
real stock shell tools, SQLite reopen/deduplication, shared Durable and Android UI
regressions. Automated tests do not inspect real credentials or make live provider
requests. The previously working ARM64 phone installation is preserved.
